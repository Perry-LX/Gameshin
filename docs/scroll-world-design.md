# Gameshin Scroll World 设计与审查记录

日期：2026-08-24

## 体验目标

主页用五幕连续滚动叙事介绍 Gameshin 是“Vibe Coding 游戏大杂烩”，不是只包含像素游戏。每一屏只表达一个重点，玩家可以正常滚动、直接跳到游戏目录，并在减少动态效果时获得静态内容流。

## 五幕叙事

| 幕 | 主题 | 玩家应理解的内容 | 主视觉 |
| --- | --- | --- | --- |
| 01 | 灵感变成玩法 | 这里有多种可直接玩的游戏 | 传送门、棋盘、魔方与跑道汇聚 |
| 02 | 策略竞技场 | 国际象棋、中国象棋、五子棋 | 棋盘竞技场 |
| 03 | 解谜工坊 | 魔方、绘画、逻辑推理 | 魔方工作台与猫咪画架 |
| 04 | 街机跑道 | 贪吃蛇、方块、平台动作 | 连续的发光跑道与跳台 |
| 05 | 游戏广场 | 不下载、不绕菜单，选择即可游玩 | 四类游戏入口汇聚到 Play 核心 |

## GPT Image 2 视觉系统

所有画面都由内置 GPT Image 2 生成，并使用第一幕作为其余画面的风格参考。统一约束：

- 深夜蓝 `#080D18` 背景。
- 柔和哑光黏土质感、锁定等距微缩世界。
- 橙色 `#F97316`、青色 `#22D3EE`、蓝色 `#60A5FA`、象牙白 `#F8FAFC`。
- 低噪点、宽阔留白、无文字、无 Logo、无水印。
- 主体集中在画面中部偏右，左侧为高对比文案保留空间。

桌面资源位于 `public/scroll-world/stills/*.webp`，共 579,870 bytes；移动端 768×512 资源位于 `public/scroll-world/stills/*-mobile.webp`，共 145,726 bytes。

## 实现策略

- 使用正常页面滚动，不劫持滚轮或触摸手势。
- 被动 `scroll` 监听配合 `requestAnimationFrame`，每帧只更新五个媒体层的 `opacity` 与 `transform`。
- 场景交界使用两张画面透明度合计约 1 的交叉淡化，消除暗闪。
- 任意时刻只显示一组标题与正文，避免文案交界叠影。
- 删除额外的章节轨道与数字进度，让玩家只关注当前场景、文案和游玩入口。
- 场景图使用全宽 `cover` 铺满视口，并禁用选择、拖拽和指针交互。
- `prefers-reduced-motion: reduce` 时完全移除滚动动画，改为普通静态卡片列表。
- 关键按钮不小于 44px；移动端按钮为 48px 以上。
- 375px 与 1280px 视口均无水平溢出。
- 首图高优先级加载，其余图懒加载；图片声明宽高，避免布局位移。

## 对抗性审查

### 吸引力

通过：首屏在一个画面中展示策略、解谜与动作线索，橙色主 CTA 是唯一强视觉焦点；五幕内容分别建立期待，不在同一屏堆叠完整游戏目录。

### 清晰度

通过：每幕只有一个眉题、一个标题、一段正文；桌面端标题与正文覆盖区域有深色渐变保护。中文首屏在 375×667 下完整显示，按钮与正文无裁切。

### 舒适度

通过：没有强制滚动、自动播放或闪烁；交界暗闪和双标题叠影已在审查中修复。减少动态效果用户获得静态页面。设置悬浮球右下角安全区与 CTA 已分离。

### 复杂度

通过：移除章节轨道、数字进度和窄屏滚动提示。首屏只有两个操作，末幕只有一个操作，进入目录后才展示分类与卡片。

### 实测证据

- 1280×720 与 1766×790：五幕均可读，背景完整覆盖水平视口，无横向溢出。
- 812×375 手机横屏：文案和 CTA 完整位于可视区域，背景铺满且无横向溢出。
- 375×812 与 375×667：英文和中文首屏无横向溢出，标题、正文、CTA 完整。
- 游戏目录 CTA：正确定位到目录，默认筛选为“全部”，11 张可玩卡片可见。
- 游戏卡片图标：11 个图标相对左上角图标容器的中心偏差均为 `dx=0, dy=0`。
- 触控尺寸：主 CTA 高度至少 51px。
- 移动端图片：运行时实际选择 768×512 的 `*-mobile.webp`，不是桌面资源。
- `npm run build`：通过。
- `npx eslint src/components/ScrollWorldHero.tsx`：通过。
- 全仓库 `npm run lint` 仍会被旧游戏源码与历史规则问题阻断；本次新增主页组件没有 lint 错误。
